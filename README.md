<< Bu proje xampp ile çalıştırılabilen basit bir CSRF-Token projesidir >>

Dosyaları htdocs içinde "csrf" adında bir klasör açarak içine ekleyebilirsiniz. 

xampp servislerini başlatıp  :

-  http://localhost/csrf/transfer.php 
-  http://localhost/csrf/protectedtransfer.php
  
adreslerini tarayıcınızda açabilirsiniz...


EN

<<This project is a simple CSRF-Token project that can be run with XAMPP >>

You can add the files to a folder named "csrf" inside the htdocs directory.

Start the XAMPP services and:

-  http://localhost/csrf/transfer.php 
-  http://localhost/csrf/protectedtransfer.php

  you can open these addresses in your browser...
